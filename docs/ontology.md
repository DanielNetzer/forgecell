# Ontology

| Primitive | Role |
|-----------|------|
| **Atom** | One step in the workflow |
| **Molecule** | Unit of work — one ticket run (atoms + ledger) |
| **Formula** | Durable YAML recipe (ticket class × repo); learning patches this |
| **Lab** | Working unit — installed runtime that runs molecules |

**Spine:** the Lab runs Molecules; each Molecule is Atoms arranged by a Formula.
