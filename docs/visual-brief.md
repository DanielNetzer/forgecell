# Visual brief

The core uses text branding for Forgecell and its four primitives: Atom, Molecule,
Formula and Lab.

**Compose once. Improve forever.**

Local UI remains a design exploration; implementation is deferred. Direction: one calm
“Runs & suggestions” screen with a run list, the selected Formula and Atom behaviors,
intake and context/action sources, and human-readable suggestions with Approve / Dismiss.
