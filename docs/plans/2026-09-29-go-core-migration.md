# Go Lab migration

Status: historical migration record. The TypeScript Lab and Node release paths have since been retired; the Go CLI and native installer are the supported paths. Later work and limitations are recorded below.

Keep the MVP goal intact: verified one-line CLI install, a fresh GitHub ticket through an isolated Molecule to an open reviewable PR with exact checks, and a real paired evaluation of the approved process lesson. Do not build the desktop UI.

## Implementation order

1. Add a Go module within lab/ alongside the reference TypeScript code. Port repository/issue binding and versioned Formula/ledger decoding with malformed-input and compatibility fixtures.
2. Port process invocation: structured stdin/stdout, Unicode, bounded output, cancellation, timeout, and provider permission fidelity. Separate core engine from command presentation.
3. Port doctor/init: deterministic capability discovery, repository evidence, explicit unknowns, saved proposals and exact human approval. Read existing Lab files without rewriting them during discovery.
4. Port isolated execution, durable operation intent/results, recovery and delivery. Harden crash gaps from the prototype. Carry explicit scope, issue/base/Formula identity and gate decisions through every Atom.
5. Add reproducible evaluation from fixed inputs and external checks, with approvals and honest missing measurements. Execute the approved comparison, retaining failures.
6. Build Go CLI artifacts and replace the Node end-user installer after parity. Verify installs/upgrades/rollback on supported hosts without source access. Establish public versus invited download policy.
7. Real dogfood issue, open PR, exact CI ledger; review changes and leave all new PRs open.

## Completion evidence

Port tests alongside behavior, not as a line-for-line transcription. Compare persisted YAML/JSON with existing fixtures. CI exercises real Git operations and fake-harness contracts before opt-in provider runs. No Go performance claim without measured CLI startup/RSS and workflow timings. Source compatibility, provider configuration, pending approvals and old ledger readability are release gates.

Go toolchain is development-only; end users receive the built CLI and do not install Go. Platform artifacts are an installer implementation detail, preserving the one-line terminal UX.
