# Ticket readiness implementation

Approved direction: `docs/design/2026-10-02-ticket-readiness.md`. Execute inline; no UI or MCP Events. Preserve approved Formula bytes and historical ledgers.

1. **Frozen contract — internal/readiness and formula.** Strict bounded analysis decoding, cited evidence, exact paths/check categories, immutable plan revisions and canonical approval digest. Separate issue content from retrieval timestamps. Validate distinct scope/review gate purposes and ordering without breaking historical recipe inspection. Tests first: malformed JSON, missing evidence, unsafe scope, stale/consequential inputs versus irrelevant timestamps.
2. **Repository evidence — onboarding/shared collector.** Retain bounded committed regular manifests, scripts, workflow/policy contents and hashes, package relationships and unknowns. No discovered script execution. Unavailable remote policy is advisory at intake. Test symlinks/submodules, limits and provenance.
3. **Analysis and intake — harness/molecule/cli.** Explicit ticket-analysis protocol on the existing binding; temporary input directory and verified tool restrictions. Unsupported capabilities stop honestly. Record analysis and pending scope gate within the same Molecule; blocked questions never reach coding. Test provider contracts and zero coding on unclear/unapproved input.
4. **Approval/resume — molecule/readiness.** Immutable proposals, append-only decisions/attempts and exclusive per-Molecule lock. Resume exact digest only after refreshing all consequential identities and persisting intent. Unknown interrupted outcomes never automatically retry. Scope amendments bind parent plan and retained tree; preserve violations/denials. Test stale inputs, concurrent approvals and recovery.
5. **Scope/checks — shared verification below molecule/evaluation.** Audit tracked/untracked/ignored source writes and explicit bounded artifact exceptions. Fresh verification checkout, frozen approved argv/definitions, filtered environment, temporary HOME, explicit setup. Retain categories and exact trees; fail on missing/failed/timed-out checks and mutation. Tests cover contamination, weakened tests/scripts, unusual paths and stale evidence. Evaluation uses explicit reviewed plans, no bypass.
6. **Delivery/docs/review.** Require readiness plus passing exact-tree verification; retain separate publication approval and exact-commit CI. Document compatibility and terminal/JSON flow. Run Go test/vet and independent whole-branch review; resolve findings.
7. **Installed candidate dogfood.** Build/install isolated candidate without replacing public preview. Clear GitHub ticket with independently reviewed acceptance proceeds through approval/checks to explicitly reviewed draft PR and exact CI. Ambiguous ticket yields useful questions, no coding/comment/PR. Exercise blocking cases; retain measurements and evidence. No merge/deployment/unapproved Formula mutation. Complete goal only after both cases pass.
